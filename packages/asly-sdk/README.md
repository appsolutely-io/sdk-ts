# @asly/sdk

An alias of [`@appsolutely-io/sdk`](https://www.npmjs.com/package/@appsolutely-io/sdk), the typed TypeScript client for the Appsolutely public API. It re-exports that package unchanged, at the same version, so every value is the same object under either name.

Install one or the other, not both:

```sh
npm i @asly/sdk@next
```

```ts
import { createClient } from '@asly/sdk';
```

Usage, mock mode and compatibility are documented in the [main package's README](https://github.com/appsolutely-io/sdk-ts#readme).
